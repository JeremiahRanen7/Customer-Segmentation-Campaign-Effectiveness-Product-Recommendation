# Dunnhumby Complete Journey - Capstone

A Streamlit app for the PGP-DSE capstone covering customer segmentation,
campaign effectiveness, and product recommendations on the Dunnhumby
"Complete Journey" dataset.

## How to run

```
pip install -r requirements.txt
streamlit run app.py
```

The app reads from two folders:

- `models/` - the saved sklearn pipeline (`scaler.joblib`, `pca.joblib`,
  `kmeans_3.joblib`). Generated by the segmentation notebooks.
- `artifacts/` - the parquet/JSON/npz files the app reads at startup.
  These come from the notebooks too:

  - `households.parquet` - household features + cluster + PCs
  - `similarity.npz` - cosine similarity matrix + household key index
  - `household_top_items.parquet` - top sub-commodities per household
  - `segment_top_items.parquet` - top items per cluster (after blocklist)
  - `regression.json` - panel-model coefficients & p-values
  - `campaign_overview.parquet` - per-campaign summary

## The four tabs

1. **Overview** - KPIs and the four-step pipeline (Raw -> Segment ->
   Effectiveness -> Recommend).
2. **Segmentation** - load a real household or type features in manually,
   the saved pipeline returns the cluster.
3. **Effectiveness** - panel-regression results. Overview sub-tab has the
   campaign portfolio, Effectiveness-by-Segment sub-tab has the coefficient
   chart and the full parameter table.
4. **Recommendations** - segment-level top 5 (blocklist applied) plus a
   household-level recommender driven by cosine similarity to the 5
   nearest neighbours.
